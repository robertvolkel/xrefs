The checks

Does the fix work
01Overview no longer looks emptyCritical
  1. Search MNS2N2222AUB and click the result card.
  2. The panel appears instantly. Watch the Overview tab for ~17 seconds.
Expect while loading
  • Shimmering bars for Datasheet, Grade, Years to EOL, Risk Rank, Country of Origin, and the whole Distribution and Environmental sections.
  • The image box shimmers — it must not say “No image” yet.
  • Next to Distributors, a shimmer bar — not the number 0. This is the single most important thing on the screen.
Expect when it finishes A View PDF link, 3 distributors, and a RoHS status. Some rows settle on a dash — that's correct, see the quirks below.
Fail if You see a wall of dashes for the whole 17 seconds, or “Distributors 0” at any point before loading finishes.
02Specs fills in instead of sitting blank
  1. Reload, click the same part again, and switch to the Specs tab while it loads.
Expect Roughly a dozen shimmering rows filling the table, then the message “No parametric data available for this part.”
Fail if The shimmer disappears and leaves an empty table with just the “Parameter / Value” header. That outcome would be worse than before the change — it's exactly what this check exists to catch.
03Specs with real data
  1. Search GRM188R71H104KA93D, click it, open Specs.
  2. Repeat with SN74LVC1G08DBVR.
Expect A few real rows immediately, shimmer rows beneath them, then the table fills with ~11 and ~14 real specifications respectively.
Fail if The “No parametric data available” message appears on a part that clearly has specifications.
04The worst case — a Chinese-manufacturer part
  1. Search YNR4030-680M and click the result (it carries a 🇨🇳 flag).
  2. Go straight to Specs.
Expect Shimmer rows immediately. Before this change, this exact case showed a bare column header over blank space for the entire load.
Does it settle cleanly
05Nothing jumps
  1. While any part loads, fix your eye on one row — Total Stock works well.
  2. Watch its position on screen at the moment the data lands.
Expect It stays exactly where it is. Values appear in place.
Fail if Rows shift up or down, or the panel jolts, as loading finishes.
The two bugs fixed alongside
06Clicking the part's own name no longer blanks it
  1. Load MNS2N2222AUB and wait for it to fully finish.
  2. In the chat, click the part number where it appears as a link.
Expect The panel reloads, but the values already on screen — datasheet, distributors, RoHS — stay visible throughout.
Fail if Those rows go blank or start shimmering again. They were already known.
07Typing while a part loadsCritical
  1. Search a part you haven't used yet and click it.
  2. Immediately — before it finishes — type something into the chat and send it, e.g. “what is this part used for?”
  3. Then repeat with a part that fails to load — a part number we can't resolve — and type in chat again before it finishes.
Expect — both runs
  • The chat replies normally. Both times.
  • The panel finishes loading and fills in with real data (first run).
  • Exactly one reply — no duplicate “here are your options” message.
Fail if The panel shimmers indefinitely, stays stuck on partial data, the chat posts two responses — or your message gets no reply at all.
Previously, typing here silently cancelled the part's data load and left the screen stuck in its loading state. This is the riskiest change in the set — it touches how the screen tracks what it's doing, not just how it looks. Step 3 exists because the first version of this script missed a real bug: it only tested a part that loads successfully, so the failure path — where a chat message was silently cancelled and never answered — went unexercised.
Did anything else move
08Nothing else changed
  1. Comparison view — load a part, find replacements, click a replacement card.
  2. Parts list — open any BOM list and click a row to open its detail popup.
Expect Both look and behave exactly as they did before.
Fail if Either surface shows shimmer bars where it used to show data, or looks different from what you remember.

Expected quirks — not bugs

Four behaviours look wrong but are either intended or already known. Please don't file these.

Some rows shimmer, then land on a dash
Grade, Years to EOL, Risk Rank, ECCN and HTS Code are genuinely empty for most parts. The shimmer means “we're checking”; the dash means “we checked, there's nothing.” The fix separates loading from empty — it can't invent data that was never published.
Chinese-manufacturer parts show “No image” straight away
Deliberate. Product images only ever come from Digikey, so shimmering there would be a tease that always ends in disappointment.
The status chip says “Active” before loading finishes
A known, separate flaw: for a part whose lifecycle status we don't yet know, the app assumes Active. Written down as an open issue — not fixed here, and not caused by this change.
Qualifications and Cross References appear late
These sections only render once they have content, so they push everything below them down when they arrive. Pre-existing, and out of scope for this work.

For anything that fails, note the check number, the part number, and what you saw instead. A screenshot mid-load is ideal — you have ~17 seconds.
